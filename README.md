### SHA-3 기반 가역 양자 회로 최적화
**ICUFN 2025**

SHA-3 θ 연산에서 발생하는 보조 큐빗 자원 소모를 줄이기 위한 가역 양자 회로를 연구했습니다.

- θ와 θ⁻¹을 함께 구현해 연산 후 보조 큐빗을 초기 상태로 복원
- θ 연산을 **4,800 CNOT gates**로 구현
- 사용한 보조 큐빗을 모두 재사용할 수 있는 회로 구조 제안

**Tech**  
`SHA-3` `Reversible Quantum Circuit` `CNOT` `Quantum Computing`

### Bitcoin 고속 채굴을 위한 양자 회로 설계
**KICS Summer Conference 2026 · ICUFN 2026**

기존 Grover 기반 Bitcoin mining의 제한된 탐색 공간과 반복 연산 구조를 개선하는 양자 채굴 구조를 연구했습니다.

- Nonce, Extra Nonce, Timestamp를 결합해 탐색 공간을 **2⁷⁶**으로 확장
- classical–quantum 전환을 줄이는 통합 탐색 구조 설계
- **Big Step algorithm의 Γ operator**를 적용해 반복적인 Grover iteration을 단일 단계 구조로 전환
- gate count, circuit depth, ancilla qubit 요구량을 기준으로 기존 구조와 비교

**Tech**  
`Bitcoin` `Proof-of-Work` `Grover Algorithm` `Big Step` `Qiskit`
