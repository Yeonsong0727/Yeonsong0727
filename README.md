## 🌟 Featured Research

### 01. Resource-Efficient Reversible Quantum Circuit for SHA-3

> Designing reversible quantum circuits for the SHA-3 θ function with reusable ancilla qubits.

- Implemented both **θ and θ⁻¹**
- Achieved **100% ancilla qubit reuse**
- Reduced unnecessary qubit disposal while maintaining circuit structure
- **Presented at ICUFN 2025**

`Quantum Circuit` `SHA-3` `Reversible Computing` `Cryptography`

---

### 02. Quantum Search for Bitcoin Mining

> Improving quantum-based Bitcoin mining by expanding the search space and reducing repeated oracle operations.

- Expanded the search space using **Nonce + Extra Nonce + Timestamp**
- Applied a proposed **Γ operator**
- Reduced repeated Grover-based operations
- Designed a resource-efficient simulation architecture

`Quantum Search` `Grover Algorithm` `Bitcoin` `Cryptography`

---

### 03. Reliable AI Training Data Management using Hashgraph

> Building a trustworthy AI training data verification framework using Hedera Hashgraph.

- Stored hashes of AI training data on **Hedera Hashgraph**
- Applied **Smart Contracts** for automated integrity verification
- Evaluated the architecture using the **CARLA simulator**
- Published in **Applied Sciences, 2025**

`Hashgraph` `Blockchain` `Smart Contract` `CARLA`
